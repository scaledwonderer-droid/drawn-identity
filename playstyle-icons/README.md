# Drawn Identity — プレイスタイルアイコン v2

- 40種類、各1024×1024px、RGBA透過PNG
- 暖色アイボリー＋控えめな古金の2色
- A：ゲーム内対応アイコン基準、B：近似ゲーム内アイコン基準、C：独自補完
- ゲーム内素材の切り出し納品ではなく、参照形状を抽出・単純化し、同一線幅と余白へ再構成
- 24〜32px表示を想定

調査根拠：公式UIガイド、ゲーム内シート（ContentType / MainCommand / GeneralAction / OnlineStatus / Perform）、XIVAPI asset path。
個別判断は「対応表.csv」を参照してください。
